# 法语词根词缀图谱 · French Word Roots Graph

把一份 9000+ 行的法语词根词缀长文档，变成一个 **Obsidian 风格的双链知识图谱**——每个词根、词缀、单词都是一个可交互的节点，点击即可展开它的派生家族与上游词根，用记忆"网"代替线性背诵。

> A force-directed, Obsidian-like graph for learning French vocabulary through its Latin roots and affixes.

## ✨ 特性

- **实时力导向图谱**：排斥力 + 中心引力 + 弹簧连线，可拖拽、有回弹，像 Obsidian 的关系图谱。
- **全局总览**：默认只显示全部 **词根（红圆）** 与 **词缀（紫菱）**，干净不拥挤。
- **点击展开家族**：点一个词根 → 它的整棵派生树展开；**子代按层级渐变着色**，**上游父链**高亮（双链）。
- **词缀关联**：前缀按词首、后缀按词尾匹配相关单词，点击即可看星系式关联。
- **浮动卡片**：点节点弹出半透明卡片，显示词性、释义、派生链、派生词、同源兄弟，全部可点跳转；卡片可拖动。
- **搜索**：按单词 / 词根 / 释义即时检索，直达对应家族。
- **纯本地、零依赖**：单个 HTML 文件 + 数据文件，**双击即可在浏览器打开**，无需联网或服务器。

## 🚀 使用

直接双击打开 [`index.html`](index.html) 即可（推荐 Chrome / Edge）。

操作：
- 点节点 → 聚焦其家族；点空白 / 「全局视图」→ 返回总览
- 滚轮缩放（以光标为中心）、拖动平移、拖动节点
- 左侧搜索框搜词；「词根 / 词缀」标签切换索引
- 详情卡片可拖动，按住标题栏移动

## 🛠 从源文档重新生成数据

图谱数据由 [`parse.py`](parse.py) 从原始 Markdown（`法语构词-1.1.md`）解析生成：

```bash
python parse.py        # 输出 graph-data.js
```

解析规则：按 Tab 缩进层级还原"词根 → 派生词 → 再派生词"的树结构，自动提取词性（n.f / n.m …）。
